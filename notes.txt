VID No. 5)
a) session : it is a transaction from database. every request has its own session.

b) Mapped = What type of data is this?
mapped_column = This is a database column.
relationship = These two database models are connected.


class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column()
    posts: Mapped[list["Post"]] = relationship()

posts: Mapped[list[Post]] = relationship(back_populates="author")
c) back_populates : it allows us to get alll things of user like to get all posts.


d) Annotated, Depends
The line to memorize
user: Annotated[User, Depends(get_current_user)]

Read it in English as:

"The user should be a User, and FastAPI should get it by calling get_current_user."

Once this sentence makes sense to you, Annotated + Depends will stop looking mysterious.
